# aclub 规则说明（链上 + 产品）

本文描述当前测试网合约 `BoothClub` 与前端/聊天服务的实际行为。金额以 **USDC（6 位小数）** 计；时长按合约常量（1 月 = 30 天，3 月 = 90 天，6 月 = 180 天）。

当前测试网参数（见 `deployments/arc-testnet.json`）：

| 参数 | 值 |
|---|---|
| 开房押金 `stakeToCreate` | 10 USDC（未达粉丝门槛时） |
| 免费开房 | 已绑定 X/推特且粉丝 ≥ 5000：**每钱包免费一间**（链下读粉丝 + 服务端签名） |
| 开房押金锁仓 | 付费开房 90 天；免费开房无押金 |
| 会籍时长选项 | 1 / 3 / 6 个月（开房时选定） |
| 平台费 | 已消耗会费的 **5%** 进 ops；群主每次 `setPrice` 另收 **5 USDC** 运营费 |
| 进池 | 已消耗会费的 **95%** 进房间费池 |
| 关账分红 | 费池 **50%** 给群主角色；**50%** 按 BOOTH 质押权重分给 Top 5（**含群主质押**） |
| 最短停留 | 中途退群至少按 **1 小时** 计费 |
| 一个地址可开多间 | 可以，每间各交一份开房押金 |

> 重要：房间本身**没有「群主续期」**。群主开房后房间一直 `active`，直到群主主动关房。到期的是**会员会籍**和**会计周期**，不是「群主资格」。

---

## 1. 角色

| 角色 | 说明 |
|---|---|
| **群主** | `createClub` 的地址；可改价、在无人时改时长、领分成、关房。开房**不会**自动变成付费会员。 |
| **会员** | 已 `join` 且 `paid > 0`；未到期可进实时聊天。 |
| **任何人** | 可对已到期会员调用 `settleExpired`；可对到期会计周期调用 `distribute`。 |
| **协议 Owner / ops** | 可改全局参数；ops 领取平台费。 |

---

## 2. 开房（群主）

1. 选择会费金额（每期 USDC）和时长（1 / 3 / 6 月）。
2. 钱包支付 **10 USDC** 开房押金，锁 **90 天**。
3. 得到新 `clubId`，群主 = 你的地址；房间立即活跃。
4. 链下可写房间名/简介（签名会话认证，不占合约）。

**可以开多间吗？** 可以。每间各锁 10 USDC。

**开房后群主要不要再付会费？**  
不必。群主身份与会员会籍分离。若群主也要进聊天，需自己再 `join`（付当期会费）。

---

## 3. 入群（会员）

1. 支付当前房间的会费（`monthlyPrice`，实为「一期会费」）。
2. 会籍从当前时刻起算，到期时间 = 现在 + 房间设定的 30/90/180 天。
3. 同一地址在同一房间：若上一笔会籍尚未结算（`paid != 0`），不能再次 join（需先 leave 或被 settleExpired）。

**入群后立刻退群：**  
至少按 1 小时消耗计费，其余退回。

**中途退群：**  
按已过时间 / 本期总时长比例消耗会费；未用部分退 USDC。  
消耗部分：5% → ops，95% → 房间费池。

---

## 4. 「到期」到底指什么？

系统里有三种容易混在一起的「到期」：

### A. 会员会籍到期（最常见）

- 到 `expiresAt` 后：前端视为非会员，**不能发消息**。
- 链上在调用 `leave` / `settleExpired` 之前，`paid` 可能仍非 0（占着「未结算」槽位）。
- **不会自动续费。** 没有「群主/会员自动扣款续期」。
- 到期后需要有人调用 `settleExpired(clubId, user)`（任何人可调），才会把整期会费计入费池（5% ops + 95% 池），并清掉会籍、腾出可再 join 的槽位。
- 结算后若想继续待：再付当期会费重新 join。

### B. 会计周期到期（分红用）

- 每个房间有 `periodStart` + 与会籍相同的时长单位。
- 周期结束后，任何人可调 `distribute`：把费池按规则记入 `usdcClaimable`，然后滚动到下一周期。
- **不 distribute 会发生什么？**  
  - 房间不关、会员不自动踢。  
  - 费池继续累积，直到有人 distribute。  
  - 群主/质押者不拿不到账上分成（钱在池子里，等关账）。

### C. 开房押金解锁（90 天）

- 与会籍 1/3/6 月无关，固定开房后 90 天。
- 解锁后，若房间无会员、无质押者，群主可 `closeClub` 取回 10 USDC 押金；费池余额记到群主可领。

---

## 5. 针对你的问题：群主「到期后没有续期」会怎样？

按合约语义，分几种理解：

### 5.1 群主没有再付会费 / 没有再 join

- **房间照常存在**，别人仍可入群、付费、聊天。
- 群主仍是群主，仍可改价、领分成（若有人 distribute）、关房（条件满足时）。
- 若群主自己也 join 过且会籍到期：群主一样进不了聊天，直到 settle 后再 join；**不影响房间归属**。

### 5.2 会计周期到了，群主不去 distribute

- 房间不消失。
- 费池钱还在合约里，暂不分到可领余额。
- 任意人之后都可以帮房间点一次 distribute。

### 5.3 开房满 90 天，群主既不关房也不管

- 押金已解锁但**不会自动退回**，仍锁在房间的 `createStake` 里，直到 `closeClub`。
- 房间继续营业。

### 5.4 会员到期后既不 settle 也不再付费

- 该用户不能聊天。
- 在 settle 前，其 `paid` 仍占槽，**不能重新 join**。
- 会费尚未进入费池；任何人 settle 后才会入池。

## 6. 群主改规则

| 操作 | 条件 | 生效范围 |
|---|---|---|
| **改会费金额** `setPrice` | 群主；房间活跃；每次付 **5 USDC** 给 ops（网站开发运营费） | **立即**对之后入群生效；已在期会员仍按当时支付金额退款/结算 |
| **改时长** `setPeriod`（1/3/6） | 群主；且 `memberCount == 0`（无人在期/未结算） | 之后新入群使用新时长 |
| **关房** `closeClub` | 群主；无会员；无质押者；开房押金已满 90 天 | 押金退回群主；剩余费池记入群主可领；房间 `active = false`，不能再 join |

有人还在期时不能改时长，避免破坏按时间比例退款。

---

## 7. 费池与分红（含 BOOTH 质押）

产品前端已弱化 BOOTH meme 展示，但合约仍保留质押分红逻辑：

1. 会员消耗的会费 95% 进 `feePool`。
2. 会计周期结束后 `distribute`：  
   - 若无合格质押者：整池给群主可领。  
   - 否则：50% 给群主角色，50% 按本周期时间加权质押分给 Top 5（群主若质押且达标，可同时进 Top 5 再分一份）。
3. 领取用 `claimUsdc`（pull，不会因某人收不了款卡住别人）。

质押相关：需有效会员；最低质押量由 `minVaultStake` 定；质押锁 90 天；加仓会刷新锁仓。

## 8. 聊天与链下规则（非合约）

| 项 | 规则 |
|---|---|
| 进房聊天 | 链上有效会员 + 签一次会话（session），之后换房一般不再弹钱包 |
| 历史消息 | 每房最多保留约 100 条 |
| 禁言 | 群主或质押 Top 5 可禁言 3 天；规则不在聊天 UI 里展示 |
| 房间名/简介、昵称/头像/推特 | 链下存储，会话或签名认证 |
| 群排名 | 链下按日权重（开房锁仓、入群额、退群、活跃等） |

断开会话/服务重启后可能需再签一次名。

## 9. 场景速查表

| 情况 | 结果 |
|---|---|
| 会员到期，没人 settle | 不能聊；不能再 join；钱未入池 |
| 会员到期，有人 settle | 整期入池；槽位清空；可再付费 join |
| 会员中途 leave | 按比例退款；消耗部分入池 |
| 群主从不 join | 房间仍正常；群主默认不能以会员身份聊天 |
| 群主 join 后到期不续 | 群主不能聊；房间仍在；他人可继续入群 |
| 周期到了不 distribute | 房间仍在；分成暂不分发 |
| 想改 1→6 个月但还有会员 | 交易失败（MembersRemain） |
| 全部结算/退群后改时长 | 可以 |
| 开房未满 90 天关房 | 失败（StillLocked） |
| 还有会员或质押者关房 | 失败 |
| 房间已 close | 不能再 join |
| 同一人开多间 | 可以，每间各 10 USDC 押金 |

---

## 10. 合约里没有的东西（避免误解）

- **没有**自动续费、没有订阅扣款。  
- **没有**「群主到期房间自动解散」。  
- **没有**踢人；禁言在链下。  
- **没有**把开房押金当会籍：押金是关房才退的创建保证金。  
- 会籍时长与开房押金锁仓（90 天）是两套时钟。
